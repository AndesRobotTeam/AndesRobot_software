# ANDESROBOT TEAM

AndesRobot es una iniciativa académica conjunta entre la Universidad Andrés Bello (UNAB) y la Universidad Santo Tomás (USTA) orientada al desarrollo, integración y simulación en plataformas de robotica social utilizando ROS 2 Humble .

El proyecto busca fomentar la investigación aplicada en robótica, inteligencia artificial y sistemas multi-robot, con especial enfoque en colaboración, interoperabilidad y transferencia tecnológica.
